## 3. Ход работы
### 3.1. Архитектура RAG системы
[
[Документы] → [Загрузчик] → [Чанкинг] → [Embeddings] → [ChromaDB]
                                                              ↓
[Пользователь] → [Вопрос] → [Поиск (top‑k)] → [Контекст] → [LLM] → [Ответ + источники]
1/Загрузка документов – чтение файлов из data/documents/ (поддерживаются .txt, .md, .pdf) с помощью класса DocumentLoader.
2/Чанкинг – разбиение текста на перекрывающиеся фрагменты (RecursiveCharacterTextSplitter), что сохраняет семантическую связность.
3/Векторизация – преобразование чанков в плотные векторные представления с использованием мультиязычной модели paraphrase-multilingual-MiniLM-L12-v2 (размерность 384).
4/Хранение – сохранение векторов и метаданных в ChromaDB (коллекция test_collection).
5/Поиск (Retrieval) – для пользовательского запроса выполняется поиск top-k наиболее похожих чанков по косинусному сходству (через similarity_search_with_score).
6/Генерация (Generation) – найденные фрагменты подставляются в промпт, и YandexGPT (или fallback‑режим) формирует ответ на русском языке с цитированием источников.]

### 3.5. Адаптация под специальность
[1/Промпт настроен на экспертизу в области компьютерного зрения для промышленного контроля. Он требует указывать тип дефекта (царапина, вмятина, загрязнение), рекомендуемый алгоритм (U‑Net, YOLO, ResNet) и метрики качества.
2/Добавлен метод _extract_cv_methods, который автоматически выделяет из ответа ключевые технологии (YOLO, Canny, сегментация, аугментация и др.).

### 3.6. Проблемы и решения
| Проблема | Решение |
|----------|---------|
| Ошибка импорта numpy / DLL при работе с PyTorch на Windows | Переход на Docker‑контейнер с Ubuntu и Python 3.10, где зависимости устанавливаются без конфликтов. |
| Некорректный путь до data/documents при запуске из разных мест | Использован динамический путь через Path(__file__).parent.parent.parent, вычисляющий корень проекта. |
| Дублирование чанков в ChromaDB при повторных запусках | Добавлен вызов store.delete_collection() перед добавлением новых документов. |--
